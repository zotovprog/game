# Style R1 — 4 направления кадрами из движка

Реальные референсы (Steam, Wikimedia, Openverse) недоступны: сетевые правила облачного окружения отклоняют эти хосты.
Вместо них — честные кадры look-dev сцены в четырёх пресетах (`?scene=lookdev&style=a|b|c|d`), board.png.

- A «Масляная тьма» — правило: свет только тёплый и только от огня, всё остальное чёрное. Близко к Amnesia/Darkwood.
- B «Уголь и янтарь» — смелое: мир монохромный, как гравюра углём (постеризация, зерно); цвет есть только у пламени.
- C «Караваджо под землёй» — украдено у живописи тенебризма: один источник, густые умбра и охра, мягкий ореол.
- D «Холодная бездна» — служит столпу «Тьма живая»: тьма не чёрная, а холодная и шевелится; тёплое = живое.
