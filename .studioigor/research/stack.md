# Research: stack — 2026-11-13

Игра: 3D-изометрия, атмосферный хоррор, браузер (десктоп + телефон), демо 5–7 минут.
Источники: npm registry (версии и даты на сегодня), references/stack.md скилла, опыт сборки look-dev в этой же сессии.

- Three.js 0.187.0 (2026-10-30): рендер + свой код. Точечный свет с cube-тенями, EffectComposer (bloom, свой grade-проход),
  onBeforeCompile для «живой тьмы» в материалах. Сборка ~0.6–0.8 МБ gzip. Всё — код, агент видит кадры через Playwright.
- Babylon.js 9.36.0 (2026-11-12): полный движок (GUI, инспектор, физика Havok). Для сцены из примитивов и одного света
  избыточен; бандл в разы больше; кастомная тьма — через Node Material/плагины материалов, дольше.
- PlayCanvas 2.24.1: движок + облачный редактор (нужен аккаунт; приватные проекты платные). Редактор агенту не нужен.
- Godot web: ~40 МБ wasm, Compatibility-рендер без объёмного тумана/SSAO; iOS Safari рискован. Отпадает для «открыл ссылку и играешь».
- Unity/Unreal: не для браузера на телефоне.

Выводы:
- Физика не нужна: столкновения — круг против сетки пещеры (свой код, 50 строк).
- WebGLRenderer (WebGL2), не WebGPU: стабильнее на телефонах и в Safari.
- Vite 8 + TypeScript; сборка в один статический каталог dist/ — открывается с любого хостинга и из артефакта.
- Что это меняет: look-dev уже работает на Three.js r187 — выбор подтверждён кадрами, а не теорией.
